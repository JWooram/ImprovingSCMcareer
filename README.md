# SCM 수요예측 도우미

판매실적과 딜러 주문을 검토하고, 6개 차종의 2026년 11월 수요를 예측해 판매계획을 확정하는 HINT 2기 1조 데모입니다.

## 실행

브라우저에서 `index.html`을 엽니다. 로컬 HTTP로 실행하려면 저장소 루트에서 `python -m http.server 8000`을 실행하고 [localhost:8000](http://localhost:8000)을 엽니다. 의존성 설치나 빌드 과정이 필요 없습니다.

## 사용 흐름

1. 홈에서 기획서를 읽거나 11월 예측을 시작합니다.
2. 실적 및 주문 검증 결과를 확인합니다. 소형 F의 7월 실적을 입력하면 예측과 백테스트에 반영됩니다.
3. 차종별 네 가지 통계 모델을 비교합니다. 최근 6개월을 한 달씩 순차 예측한 뒤 MAPE가 가장 낮은 모델을 선택합니다.
4. 오차 기준을 넘었거나 특이 상황이 표시된 차종의 수량과 조정 사유를 확인합니다.
5. 확정 계획에서 예측값과 확정값을 비교하고 CSV로 내려받습니다. 최근 12개 확정 기록은 같은 브라우저에서 열 수 있습니다.

예시 실적과 주문은 재현용 데이터입니다. 모델별 수치와 예상 범위는 이 데이터에서 계산됩니다. 주문은 중복을 점검하며 통계 모델은 판매실적을 사용합니다. 확정 기록은 브라우저 로컬 저장소에 저장됩니다.

## 개선 우선순위

| 순서 | 개선 | 확인 방법 |
| --- | --- | --- |
| 1 | 실적·주문 CSV 검증. 주문번호가 같고 수량이 다른 경우에는 충돌로 분류하고, 결측·추정·실적을 구분합니다. | 중복과 충돌 각각의 처리 결과 및 원본 행을 확인합니다. |
| 2 | MAPE와 함께 WAPE와 편향을 표시하고 1·2·3개월 예측을 각 기간별로 백테스트합니다. 확정 수량과 원래 예측 수량을 실적에 각각 비교합니다. | 기간별 오차, 과대·과소 예측, 수동 조정 전후 오차를 비교합니다. |
| 3 | 단일 8% 기준을 차종별 비용과 위험 기준으로 검증합니다. 공급 제약과 주문 급증을 별도 예외로 관리합니다. | 예외 검토 건수, 놓친 예외, 계획 확정 소요 시간을 비교합니다. |
| 4 | 공동 사용이 필요할 때 공유 저장소와 SCM·영업·생산기획 권한을 추가하고 승인자·변경 시각·원본 예측을 보존합니다. | 여러 사용자가 같은 계획을 검토하고 변경 이력을 추적할 수 있는지 확인합니다. |
